# Paseo GenUI 视觉规范 v0.2（亮色 + 暗色，实测自 ChatGPT 网页版计算样式，2026-10-20）

> 来源：用户在 ChatGPT 网页版用脚本导出的 computed style（亮、暗各一份）。尺寸两种主题完全相同，只有颜色不同，见第 7 节。
>
> **地位（RFC v0.4）**：GenUI 组件的尺寸、字号、圆角、间距、配色全部以本文件为准，实现为一套独立的 GenUI 设计变量（亮/暗两套），不映射、不混用 Paseo 主题颜色；亮暗切换跟随 Paseo 当前主题。验收清单见 `genui-visual-acceptance.md`。

## 3. 容器

- **描边卡片**：1px rgba(0,0,0,.1) 边框，圆角 16，内边距 12，子元素间距 8–12，与上文间距 16。
- **浅底卡片**：底色 #FCFCFC，无边框，圆角 12，内边距 12，间距 4–8。用于卡片内的子块（如单个指标）。
- **grid**：间距 8；grid-item 透明无边框。
- **row**：间距 8 或 12，常用 align=center、justify=between。
- 原则：最多两层（描边卡片里放浅底子块），不叠第三层。

## 4. 组件规则（对应 v1 十个组件）

### metric / metricComparison

- 浅底子块（#FCFCFC，圆角 12，内边距 12），多个用 grid（间距 8）排列。
- 标签：text xs 12/16 #5D5D5D，可用 500 字重；数值：title 2xl 24/32 600 等宽数字；单位或补充用 text sm。
- 变化值：title lg 18/28 600，左间距 8。颜色由 `compare.changeIntent` 决定，不按数值正负：`bad` 用危险色（#E02E2A），`good` 用成功色（#008635），`neutral` 或省略用次要文字色（#5D5D5D）。
- 变化条（参考图 A 中百分比下方的条）：尺寸同 progress，长度为变化幅度的绝对值；填充色与变化值颜色一致，85% 透明度。

### progress

- 高 7px，圆角 full；底槽 #F3F3F3；填充用语义色并带 85% 透明度（例：rgba(42,163,106,.85)）。
- 右侧百分比：text sm 14/20 500 等宽数字，左间距 8。

### chart.bar

- 组件高度按容器宽度取值：宽度 ≥ 600px 时 27rem（432px）；更窄时取宽度的 0.72 倍，最小 280px（初始值，iOS 实测后调整）。
- 柱子：顶部圆角 8，同组相邻柱间隔 4px，填充用渐变（同色由实到浅）、描边同色。
- 系列配色顺序：#539AF8（蓝）、#6BC67F（绿）、#EF8B57（橙）、#F8D45D（黄）。
- 网格线：rgba(0,0,0,.05)，1px，虚线 3/3；无轴线。
- 刻度文字：12px，#5D5D5D。
- 图例：底部，色点 10×10 圆形，间距 6，项内边距 4×8。

### chart.line

- 线宽 2px，颜色同上序列；网格线与刻度同柱状图；数据点为半径约 4.5 的圆点。

### chart.pie（v1）

- 扇区描边 2px #F3F3F3 作为分隔，配色同上序列；类别超过 4 个时序列色循环使用并降低明度区分。
- 高度规则同 chart.bar；图例在图下方，规则同 chart.bar 图例，显示类别名与百分比。

### table

- 单元格 text sm 14/20，内边距 8（首列左 0、末列右 0）；表头 600 字重。
- 行高约 36；无竖线；表格宽度可外扩到正文两侧留白。

### priorityList（用 list 实现）

- 编号/图标列表，项间距 12，项内间距 8，可用实线连接点（connector solid）。
- 图标按 `decision`：`change` 为带外环的实心圆点（正文色），`adjust` 为实心灰点（次要文字色），`keep` 为成功色的勾选圈；与参考图 C 一致，区分不只靠颜色。
- `priority`（可选）不单独显示徽标（参考图 C 没有徽标，且逐条徽标会显得醒目杂乱）：只用于同一 `decision` 内的排序（high 在前），并在无障碍标签中读出。
- 标题 text md 500–600，正文 text md 16/26 #0D0D0D 或 sm。
- 项之间可用 1px 分隔线。

### badge（附带）

- 12/20 500，字距 0.3px，圆角 full，左右内边距约 6.65，背景为语义色 15% 透明度、文字为语义色。

## 5. 交互件（v2 参考）

- 按钮：高 28（小）/36（主），14px 500，圆角 full，主按钮白字深底。
- 输入框 / select / date-picker：高 40；textarea 内边距 10×14。
- 复选框：20px 圆形，1px #CDCDCD 边框。
- segmented-control：高 32；slider：高 24。

## 6. 流式

- 正文按词逐个揭示；卡片出现前用 loading-block（浅蓝 #E8F3FE 占位，固定高度）。

## 7. 暗色配色（与亮色对照，尺寸不变）

| 用途                          | 亮色                     | 暗色                           |
| ----------------------------- | ------------------------ | ------------------------------ |
| 正文 / 标题                   | #0D0D0D                  | #EDEDED                        |
| 次要文字、标签、caption、刻度 | #5D5D5D                  | #CDCDCD                        |
| 第三级文字（2xs）             | #8F8F8F                  | #AFAFAF                        |
| 卡片边框                      | rgba(0,0,0,.10)          | rgba(255,255,255,.15)          |
| 分隔线                        | rgba(0,0,0,.10)          | rgba(255,255,255,.05)          |
| 浅底子块                      | #FCFCFC                  | #0E0E0E                        |
| 进度条底槽                    | #F3F3F3                  | #212121                        |
| 进度填充                      | rgba(42,163,106,.85)     | 不变                           |
| 行内代码底                    | #F3F3F3 82%              | #212121 82%                    |
| 危险 / 降幅                   | #E02E2A                  | #FF6764                        |
| 成功徽标文字                  | #008635                  | #04B84C                        |
| 复选框边框                    | #CDCDCD                  | #5D5D5D                        |
| 主按钮                        | 深底白字                 | 浅底黑字 #0D0D0D               |
| 加载占位                      | #E8F3FE                  | #133463                        |
| 图表网格线                    | rgba(0,0,0,.05) 虚线 3/3 | rgba(255,255,255,.05) 虚线 3/3 |
| 图表系列 1 蓝                 | #539AF8                  | #1F4E94                        |
| 图表系列 2 绿                 | #6BC67F                  | #3A843F                        |
| 图表系列 3 橙                 | #EF8B57                  | #AC4F23                        |
| 图表系列 4 黄                 | #F8D45D                  | #D9A337                        |
| 饼图扇区分隔描边              | #F3F3F3 2px              | #303030 2px                    |

要点：

- 暗色下图表系列色明显压暗、降饱和，而不是简单沿用亮色。
- 暗色边框比亮色更不透明（15% vs 10%），分隔线反而更淡（5%）。
- 浅底子块在暗色下比页面更黑（#0E0E0E），靠边框和明度差区分层次。
