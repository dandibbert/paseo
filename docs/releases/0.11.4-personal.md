此次个人版在 0.11.4 基础上加入聊天卡片（GenUI），版本号仍沿用 0.11.4。

- 新增聊天卡片：Agent 可以通过 `render_ui` 工具在聊天里直接画原生卡片，代替 Markdown 表格和数字列表。支持数值对比、关键指标、进度、柱状图（类别名放不下时自动横向）、折线图、饼图、表格、修改建议、步骤与里程碑，以及成组展示。卡片可以“复制为文本”和“查看数据”。
- 卡片可以带后续按钮：点按后先显示要发送的原文，确认后作为你的消息发给 Agent；只在最新一轮、Agent 回答完后可用。
- 能调用 `render_ui` 的 Agent 会在 system prompt 里收到何时画卡片的指引。设置 → 主机 → Agents → “聊天卡片指引”可以关闭；设置 → 聊天 → “显示聊天卡片”可以只在本设备关闭卡片显示。Claude 和 Codex 调用 `render_ui` 不再弹权限确认。
- 推送通知、`paseo logs`、`wait_for_agent` 和分叉上下文里，卡片显示为标题和摘要，不再出现原始 JSON。
- 修复已归档的失败 Claude/Codex 子代理在重启或更新后重新出现。
- 卡片需要 Mac 和手机 App 同时更新；旧版 App 只显示卡片的文字摘要。

同时包含上一次 0.11.4 个人版的内容：合入上游 main 截至 `74c8172f8ef48a3eec88dbcd0df3fc2932d8c6b2` 的更新（24 个提交，上游已进入 0.12.0-beta.1 线）。

- 修复 Pi（@gotgenes/pi-subagents）后台子代理结束后卡片一直停在运行中：子代理完成、被引导收尾、中止或出错时，卡片会实时收尾，不再依赖主 Agent 调用 get_subagent_result；进度通知和子会话文件不会再把已结束的卡片改回运行中。
- 恢复（resume）子代理会让原卡片重新进入运行中，上一次运行迟到的完成消息不会提前结束新一次运行。
- 重新打开历史会话时，子代理卡片按 Pi 会话里记录的运行结果收尾；只在部署后新产生的记录上生效。
- 后台 Claude 子代理的卡片会显示其操作日志；空闲的 OMP agent 收到后续消息时会启动；Claude 在设置变更后保持当前轮次运行。
- 修复问题回复失败后无法恢复、iOS 全屏输入框被键盘遮挡、iOS 侧边栏拖动被打断后行卡住、安卓听写在音频中断后停止等问题；矮屏幕上主页操作可以够到。
- 聊天里的文件夹链接在文件面板中打开并展开内容；OpenCode 的无效工具调用会返回可操作的错误；插件重载会等待完成而不是超时失败。
- 保留此 fork 的高级模型编辑器、自定义 Codex 模型目录、上下文窗口设置及 relay 恢复功能。

这是 macOS 个人构建，提供 Apple Silicon（arm64）和 Intel（x64）安装包。使用 ad-hoc 签名，未经 Apple 公证；保留 Hardened Runtime 和此 fork 的签名策略。替换正在运行的 Paseo 前，请先等待 agent 任务结束。

发布前检查包含两种架构的构建、签名检查、应用启动检查，以及在独立 macOS 15 运行器上对 ZIP 和 DMG 的安装验证。附件提供源码版本、SHA-256 校验和、构建签名报告和独立安装签名报告。
