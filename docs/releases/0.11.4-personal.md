此次个人版将 `dandibbert/paseo` 从上游 0.11.2 同步至 0.11.4，并包含截至 `0d7a234e6381576d32015dbd54469497708e416f` 的上游 main 更新（60 个提交）。

- 新增 Hoplite 提供商（ACP 目录，需手动启用），并为 Add provider 目录增加搜索；添加失败时改为弹出提示。
- 修复 Hoplite 在已关联项目的工作区里无法发现模型的问题，以及插件提供商（如 Antigravity、Muse Code）被错误地提供 Remove 的问题。
- iOS、Android 和网页端统一使用同一个 Markdown 渲染器，并改进原生文字选择。
- 紧凑布局：手机顶部栏、输入框和设置菜单重新打磨；可从手机顶部菜单运行并查看工作区脚本；侧边栏、底部按钮和设置项增加点按反馈。
- 长对话渲染更省资源，并可在其他 agent 输出时读取缓存的聊天；用 Page Up/Page Down 滚动聊天。
- 修复刷新后后台工作区重新出现、安卓选中文字时聊天跳动、本地 WAV 转写无法启动等问题。
- 保留此 fork 的高级模型编辑器、自定义 Codex 模型目录、上下文窗口设置及 relay 恢复功能。

这是 macOS 个人构建，提供 Apple Silicon（arm64）和 Intel（x64）安装包。使用 ad-hoc 签名，未经 Apple 公证；保留 Hardened Runtime 和此 fork 的签名策略。替换正在运行的 Paseo 前，请先等待 agent 任务结束。

发布前检查包含两种架构的构建、签名检查、应用启动检查，以及在独立 macOS 15 运行器上对 ZIP 和 DMG 的安装验证。附件提供源码版本、SHA-256 校验和、构建签名报告和独立安装签名报告。
