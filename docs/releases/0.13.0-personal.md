此次个人版合入上游 0.12.0 和 0.13.0 正式版（截至上游 main `d0fd2e532`，共 158 个提交），版本号随上游更新为 0.13.0。

- **Relay 安全**：设了密码的 daemon 现在也要求 relay 连接提供密码；没设密码的 daemon 不受影响。新版 App 和 daemon 之间通过 relay 会自动改用可防重放的加密握手，旧版仍可连接。自建 Relay 服务端无需更新。
- **跨主机**：daemon 可以连接其他机器上的 Paseo（`paseo host add`），Agent 能在那些机器上创建、指挥和查看 Agent。
- **Agent 状态与通知**：daemon 重启后 Agent 不再一直显示运行中，完成通知可以恢复；子 Agent 的汇报和完成通知合并成一条消息。
- **Claude**：打开很长的历史和列出会话时不再把整段记录读进内存；批准计划时可以回到 Auto 模式。
- **终端**：可以往 Agent 的终端界面粘贴图片、拖入文件（远程主机也可以）；iOS 和 Android 统一使用原生终端渲染。
- **界面**：侧边栏工作区可按创建时间、最近提示或手动排序；Explorer 在手机、平板和桌面上使用同一套标签；Command Center 结果显示统一的状态图标；子 Agent 行显示模型和推理强度；支持折叠屏手机。
- **插件**：插件可以提供文件面板、跟随 App 语言翻译，并使用 Paseo 的 Markdown 渲染。
- 0.13.0 之后的修复：SSH 隧道连接失败时不再导致调用方崩溃；Web 端很长的“导入会话”列表保持流畅；带端口、冒号或用户名的网址识别为一个完整链接。
- 还包括 iOS、Android、Markdown、用量显示和工作区等方面的大量修复，详见上游 CHANGELOG。

保留此 fork 的功能：聊天卡片（GenUI）及其后续按钮和指引开关、Pi 技能管理、`list_agents` 的 related 范围、终端安全输入、relay 连接恢复、高级模型编辑器、自定义 Codex 模型目录、上下文窗口设置，以及 Pi 子代理卡片的收尾修复。

这是 macOS 个人构建，提供 Apple Silicon（arm64）和 Intel（x64）安装包。使用 ad-hoc 签名，未经 Apple 公证；保留 Hardened Runtime 和此 fork 的签名策略。替换正在运行的 Paseo 前，请先等待 agent 任务结束。

发布前检查包含两种架构的构建、签名检查、应用启动检查，以及在独立 macOS 15 运行器上对 ZIP 和 DMG 的安装验证。附件提供源码版本、SHA-256 校验和、构建签名报告和独立安装签名报告。
